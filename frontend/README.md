# AI Website Cloner

An AI-powered website cloning application that analyzes
publicly accessible websites and generates responsive
React websites using AI.

## Features

- Website URL input
- Website structure and content analysis
- AI-powered React website generation
- Responsive website design
- Website preview
- Natural-language website modifications
- Generated code validation
- Error handling

## Technologies Used

### Frontend
- React
- TypeScript
- Vite
- CSS

### Backend
- Python
- Flask
- Flask-CORS
- Playwright

### AI
- Google Gemini API

## Project Structure

- `frontend/` - React user interface
- `backend/` - Flask API and website analysis
- `generated_sites/` - Generated React websites
